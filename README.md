# CV Cá Nhân - React + Vite

Đây là website CV cá nhân của bản thân, được xây dựng bằng **React + Vite**.

---

## 1. Link demo

Website demo sau khi deploy lên Vercel:

```txt
[link demo web](https://react.dev/learn/react-compiler/installation).
```

---

## 2. Công cụ sử dụng

1. **Visual Studio Code**: dùng để viết và chỉnh sửa code.
2. **React + Vite**: dùng để xây dựng giao diện website.
3. **React Router DOM**: dùng để chuyển trang trong website.
4. **CSS thuần**: dùng để thiết kế giao diện, hiệu ứng và responsive.
5. **LocalStorage**: dùng để lưu chế độ sáng/tối.
6. **GitHub**: dùng để lưu trữ source code.
7. **Vercel**: dùng để đẩy website lên hosting và chia sẻ link demo online.

---

## 3. Cấu trúc giao diện

Website được thiết kế theo phong cách hiện đại, có hiệu ứng ánh sáng, nền động, card trong suốt và bố cục responsive phù hợp cho cả máy tính và điện thoại.

Giao diện chính gồm phần ảnh cá nhân ở trang chủ, menu điều hướng dạng orbit, các trang nội dung riêng và header dùng chung cho chế độ sáng/tối cũng như nút quay về trang chủ.

---

## 4. Chức năng chính

1. Hiển thị website CV cá nhân.
2. Có hiệu ứng ảnh cá nhân và menu orbit.
3. Nhấn vào ảnh để hiện các mục điều hướng.
4. Trên điện thoại, nhấn icon lần 1 để hiện tên mục, nhấn lần 2 để vào trang.
5. Chuyển trang bằng React Router DOM.
6. Có chế độ sáng/tối.
7. Lưu trạng thái sáng/tối bằng LocalStorage.
8. Giao diện responsive cho máy tính và điện thoại.
9. Có thể xem demo online thông qua link Vercel.

---

## 5. Cách chạy dự án

### Bước 1: Tải source code về máy

Có thể tải file `.zip` hoặc clone project từ GitHub.

```bash
git clone link-repository-cua-ban
```

### Bước 2: Mở project bằng Visual Studio Code

```bash
cd ten-thu-muc-du-an
code .
```

### Bước 3: Cài đặt thư viện

```bash
npm install
```

### Bước 4: Chạy dự án

```bash
npm run dev
```

### Bước 5: Mở website trên trình duyệt

Sau khi chạy lệnh trên, terminal sẽ hiện đường dẫn, thường là:

```txt
http://localhost:5173
```

Mở đường dẫn đó trên trình duyệt để xem website.
